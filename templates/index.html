👩‍💻 About the Developer

Aanchal

This weather application was built as part of Tech Assessment 2 for the PM Accelerator program.

Tech Stack
  • Backend: Python Flask, SQLAlchemy
  • Database: SQLite (SQL)
  • Weather API: Open-Meteo (free, no key)
  • Geocoding: Nominatim / OpenStreetMap
  • Maps: Leaflet.js + OpenStreetMap
  • Charts: Chart.js
  • Frontend: Bootstrap 5
API Integrations
  • 🌡️ Open-Meteo — Current, historical & forecast weather
  • 🗺️ Nominatim — Geocoding (city, zip, GPS, landmarks)
  • 🌬️ Open-Meteo Air Quality — AQI, PM2.5, UV index
  • 📖 Wikipedia — Location summaries
  • ▶️ YouTube Data API — Travel videos
  • 🌐 RestCountries — Country information
  • 🗺️ Leaflet + OpenStreetMap — Interactive maps

📋 Features Checklist
2.1 CRUD Operations
  • ✅ CREATE — Fetch weather for location + date range, store in SQLite
  • ✅ READ — View all stored records with pagination
  • ✅ UPDATE — Edit location/dates, re-fetch weather data
  • ✅ DELETE — Remove records from database
  • ✅ Date range validation (format, order, bounds)
  • ✅ Location validation via geocoding (fuzzy match)
2.2 API Integrations
  • ✅ YouTube videos for location
  • ✅ Interactive map (Leaflet + OpenStreetMap)
  • ✅ Wikipedia location summaries
  • ✅ Country information (RestCountries)
  • ✅ Air Quality Index (Open-Meteo)
  • ✅ Sunrise/Sunset data
2.3 Data Export
  • ✅ JSON export
  • ✅ CSV export (comma-delimited)
  • ✅ XML export
  • ✅ PDF export (with tables)
  • ✅ Markdown export
